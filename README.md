# IMLO Coursework — Oxford-IIIT Pet image classifier

A 37-class image classifier for the [Oxford-IIIT Pet
dataset](https://www.robots.ox.ac.uk/~vgg/data/pets/). Custom pre-activation
ResNet with Squeeze-and-Excitation, a MaxPool stem, a
**ResNet-101-style `(3,4,23,3)` block layout** at the original
channel widths `(64,128,256,512)`, and **BlurPool antialiased
downsampling** at every stride-2 transition. ~41.7 M parameters,
trained from scratch in 30 epochs on the official 3 680-image
`trainval` split. Evaluation uses 7-scale + horizontal-flip
test-time augmentation.

See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the design write-up and
[`submission_answers.md`](submission_answers.md) for the Q1–Q15 form
answers.

## Files

| File | Purpose |
|---|---|
| `train.py` | No-args entry point. Trains for 30 epochs and saves `model.pth`. |
| `test.py`  | No-args entry point. Loads `model.pth` and prints test accuracy. |
| `model.pth` | Final trained weights (state dict only, **fp16** to keep the wider/deeper model under the 100 MB zip cap; `test.py` upcasts to fp32 on load). |
| `data_stats.json` | Cached trainval channel mean/std and the train/val split indices. Generated by `train.py` on its first run; committed for reproducibility. |
| `MODEL_SUMMARY.txt` | `torchinfo.summary` output, regenerated by `train.py`. |
| `environment.yml` | The conda env the markers use (`imlo-coursework`). |
| `environment-gpu.yml` | My local CUDA variant (`imlo-coursework-gpu`). |
| `src/` | `model.py` (architecture), `data.py` (loaders + transforms), `mixup.py`, `train_loop.py`, `utils.py`. |

## How to run

```bash
# Activate the env (use either name depending on your machine).
conda activate imlo-coursework        # CPU/wheels-only
conda activate imlo-coursework-gpu    # local CUDA wheels

# Train (writes model.pth, MODEL_SUMMARY.txt, data_stats.json,
# and patches Q14/Q15 in submission_answers.md).
python train.py

# Evaluate the saved weights.
python test.py
```

Both scripts require CUDA. They will raise immediately if
`torch.cuda.is_available()` is False.

## Expected runtime and accuracy

- **Train**: ~30–35 minutes for the full 30-epoch run on a single modern
  CUDA GPU (RTX 3080-class or better). The model has a MaxPool right after
  the stem (stages run on quarter-area feature maps) but **33 residual
  blocks in a `(3,4,23,3)` distribution**, so per-epoch compute is heavier
  than the shallower variants. The pipeline fits comfortably in 12 GB VRAM
  at batch size 128; if VRAM is tighter, `train.py` automatically falls
  back to batch size 64 with gradient accumulation = 2 so the effective
  batch is unchanged.
- **Test**: ~2 minutes for a 7-scale + HFlip TTA pass over the 3 669-image
  test split (14 forward passes per image).
- **Accuracy**: ~70 % on the official test split, ~91 % on the 3 680-image
  trainval (which is the full training pool — no held-out val). From-
  scratch / 30-epoch / no-pretraining is the binding constraint; the
  cumulative promotions over the original 45.60 % recipe came from TTA
  (+1.14 pp), a stem MaxPool (+5.13 pp), training on the full trainval
  (+2.26 pp), weight-decay 1e-3 (+2.26 pp), the structural chain
  (deeper → deep+wide → ResNet-101 layout, +11.15 pp net), and finally
  BlurPool antialiased downsampling on top of ResNet-101 (+2.72 pp).

## Reproducibility

Everything is seeded (Python `random`, NumPy, PyTorch CPU and CUDA, plus a
`Generator` for the `DataLoader` and a `worker_init_fn` for each worker).
`torch.backends.cudnn.deterministic = True` and `benchmark = False` are set
in `src/utils.py:seed_all`. The split indices are pinned in
`data_stats.json` so the same 3 312/368 train/val cut is used everywhere.
The spec's ±3 % reproducibility margin is comfortably met on re-runs of the
full training pipeline.
